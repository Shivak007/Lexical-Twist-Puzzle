# Lexical Twist Puzzle

Lexical Twist Puzzle is a console-based Java application that processes two words and performs transformations based on logical conditions.

## Features
- Accepts two words as input
- Validates single-word constraint
- Checks reverse relationship (case-insensitive)
- Transforms word if reverse match
- Analyzes vowel–consonant distribution
- Fully modular OOPS architecture (UC8)

## Project Structure
- main → README only
- develop → Final UC8 implementation
- feature/* → One branch per use case (GitFlow)

## Technologies
